# Plugin: Real Data Collector & Scraper

## ХАТУУ ХОРИГЛОХ ДҮРЭМ:
1. **NO AI GENERATED / SYNTHETIC DATA:** "Lorem ipsum", хиймэл зохиосон номын нэр, хуурамч зураг/текст үүсгэхийг ХАТУУ ХОРИГЛОНО. Бүх дата бодит байх ёстой.
2. **SOURCE VERIFICATION:** Татаж авсан өгөгдөл бүр бодит URL, бодит зохиогч, бодит бүтээгдэхүүний эх сурвалжтай байна.

## АЖИЛЛАХ 4 ҮЕ ШАТ:

### 1. Schema Alignment (Апп-ын бүтцийг тодорхойлох)
- Прожект доторх Data Models, Types, Database Schema-г шинжилж ямар бодит өгөгдлийн талбарууд (fields) шаардлагатай байгааг тодорхойлно.

### 2. Sourcing Strategy (Бодит эх сурвалжийг сонгох)
Апп-ын салбараас хамааран бодит эх үүсвэрийг сонгож тодорхойлно:
- **Номын апп бол:** Open Library API, Google Books API, Project Gutenberg, эсвэл Goodreads/Amazon-ий нээлттэй өгөгдөл.
- **Худалдаа / Дэлгүүр бол:** DummyJSON, FakeStore (бодит зургуудтай), эсвэл нээлттэй бүтээгдэхүүний сангууд.
- **Мэдээ / Контент бол:** RSS feeds, Reddit API, Wikipedia API, нээлттэй нийтлэлүүд.
- **Тусгай салбар / Монгол контент бол:** Бодит вебсайтуудаас BeautifulSoup/Puppeteer ашиглан хусах скрипт бэлтгэх.

### 3. Collection Script Execution (Өгөгдөл татах скрипт ажиллуулах)
- Прожект дотор `scripts/fetch_real_data.py` эсвэл `scripts/fetch_real_data.ts` скрипт үүсгэнэ.
- Скрипт нь шууд бодит эх сурвалжаас хүсэлт явуулж бодит 20-50+ өгөгдлийг (жинхэнэ зургийн CDN линк, бодит үнэ, бодит тайлбар, үнэлгээ) татаж авна.
- Татаж авах явцад эвдэрсэн зураг, хоосон утгуудыг цэвэрлэж (sanitize) апп-ын моделд яг нийцүүлэн хөрвүүлнэ.

### 4. Output Persistence (Өгөгдлийг байршуулах)
Татаж цэвэрлэсэн бодит өгөгдлийг апп-ын технологид тохируулан хадгална:
- `assets/data/real_data.json` эсвэл `src/data/realData.ts`
- SQLite / Local Database seed script хэлбэрээр байршуулна.

## ТАЙЛАНГИЙН БҮТЭЦ:
Өгөгдлийг цуглуулж дуусмагц `DATA_SOURCE_LOG.md` файл үүсгэж:
- Өгөгдлийг хаанаас, ямар эх сурвалжаас татсан (API endpoint, website source).
- Нийт хэдэн ширхэг бодит өгөгдөл амжилттай татагдсан.
- Апп-ын ямар файл, хавтаст өгөгдөл хадгалагдсаныг тайлагнана.
