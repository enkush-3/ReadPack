## АЖИЛЛАХ 4 АЛХАМ:

### Алхам 1: Шинжилгээ ба Sub-Agent Төлөвлөлт (Spawning)
Шүүмж дээрх согог тус бүрд зориулан тусгай sub-agent-ууд томилно:
- **Sub-Agent Name:** Тухайн асуудлын нэрээр (жишээ нь: `reader-engine-specialist`, `bookmark-sqlite-keeper`, `contrast-theme-fixer`).
- **Target Files:** Агент тус бүрийн хариуцах тодорхой файлуудын жагсаалт (Scope Isolation).
- **Goal:** Шүүмж дээрх алдааг эксперт түвшинд хүргэж засах ганц зорилго.

### Алхам 2: Зэрэгцээ ба Дараалсан Гүйцэтгэл (Parallel & Sequential Batches)
- **Parallel Batch:** Өөр өөр файлууд дээр ажиллах, хамааралгүй sub-agent-уудыг зэрэг ажиллуулна.
- **Sequential Batch:** Дата бааз, архитектурын суурь өөрчлөлт шаардлагатай хамааралтай sub-agent-уудыг дэс дараалан ажиллуулна.

### Алхам 3: Автомат Local Git Commit
- Зэрэг ажилласан batch эсвэл sequential sub-agent бүр өөрийн ажлыг дуусмагц автоматаар цэгцтэй Git commit үүсгэнэ (`feat:`, `fix:`, `refactor:` стандартын дагуу).
- **GitHub руу шууд PUSH ХИЙХИЙГ ХОРИГЛОНО.** Зөвхөн хэрэглэгч тушаасан үед л push хийнэ.

### Алхам 4: Тайлан
Ажил дуусмагц ямар sub-agent-ууд юу зассаныг тайлагнаж, шалгуулахаар шилжүүлнэ.
