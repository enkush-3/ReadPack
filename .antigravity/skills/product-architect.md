# Product Manager & System Architect Skill
Хэрэглэгч шинэ апп эсвэл функц захиалахад шууд код бичилгүйгээр `PRD.md` болон `TASKS.md` файлуудыг дараах бүтцээр үүсгэ:
1. **Competitor Analysis:** Тухайн төрлийн дэлхийн шилдэг 3 апп-ыг шинжилж, тэдгээрт байдаг 10-15 нарийн функц (Micro-features, жишээ нь номын апп бол: Auto-save scroll offset, Sepia/Dark mode, Font scaling, Bookmark, Reading streak, Offline cache)-ийг жагсаа.
2. **Complete Sitemap:** Орхигдож болзошгүй Onboarding, Forgot Password, Profile, Edit Profile, Settings, Search Filters, Empty States хуудсуудыг заавал багтаа.
3. **Data Schema & Local Persistence:** Бүх моделууд болон утасны санах ойд (Local Storage / SQLite) хадгалах төлөвүүдийг тодорхойл.
4. **Milestone Execution:** Ажлыг 5 Milestone-д хувааж (`TASKS.md`), нэг удаад зөвхөн 1 Milestone-ийг 100% бүрэн кодчилж дуусгаад `[x]` гэж тэмдэглэ.
