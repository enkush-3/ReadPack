# Skill: Quality Loop Orchestrator (Threshold < 5)

## ЗОРИЛГО:
Аппликейшны согогийг шат дараатай бууруулж, production түвшинд хүргэх хүртэл "Шүүмжлэх -> Засах" циклийг автоматаар удирдах.

## ДАВТАЛТЫН УРСГАЛ (THE LOOP):

1. **АЛХАМ 1 (Аудит):** 
   - `production-critic` скиллийг дуудаж, одоогийн прожектыг шалгуулан `CRITIQUE_REPORT.md` тайлан үүсгүүлнэ.
   - Тайлан дахь **Нийт илэрсэн согогийн тоог (Total Defects)** уншина.

2. **АЛХАМ 2 (Нөхцөл шалгах):**
   - **ХЭРЭВ Согогийн тоо < 5 бол:**
     - Циклийг ШУУД ЗОГСООНО.
     - Прожект production түвшинд хүрснийг зарлаж, хэрэглэгчид: 
       `"Бүх ноцтой согогууд засагдаж, нийт шүүмжийн тоо 5-аас бага ([Тоо]) боллоо. Прожект бэлэн боллоо! GitHub руу push хийх үү?"` гэж асууна.
   - **ХЭРЭВ Согогийн тоо >= 5 бол:**
     - Дараагийн алхам руу автоматаар шилжинэ.

3. **АЛХАМ 3 (Засвар):**
   - `autonomous-builder` скиллийг дуудаж, тайлан дээрх дугаарлагдсан согогуудад тохирох динамик sub-agent-уудыг томилуулан, кодчилж засуулна.
   - Бүх засварууд локал Git commit хийгдэж дуусна.

4. **АЛХАМ 4 (Давтах):**
   - Засварын дараа АЛХАМ 1 рүү буцаж, дахин шинэ `production-critic` ажиллуулж согогийг дахин тоолно.

## ХАМГААЛАЛТ (Circuit Breaker):
- Систем төгсгөлгүй эргэхээс сэргийлж нэг удаад хамгийн ихдээ 4 бүтэн давталт (Max 4 Iterations) хийнэ. Хэрэв 4 дэх давталт дээр согогийн тоо 5-аас буухгүй бол зогсоод хэрэглэгчид үлдсэн асуудлуудыг тайлагнана.
